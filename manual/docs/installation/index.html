Install the SDK

Choose the installer for your operating system and processor. Installation works offline in your own account. Each SDK version has its own directory. The native libraries, headers, language bindings, examples, notices and example.klv are installed together. Leave the web component selected to include the browser decoder, Node example and npm tarball under web/.

TargetDownload and runInstalled SDK root
Windowsx64Open the signed libmisb-sdk-VERSION-windows-amd64-setup.exe. The publisher is IMPLEOTV SYSTEMS LTD.%LOCALAPPDATA%\ImpleoTV\libmisb\VERSION
Linuxx64Run sh ./libmisb-sdk-VERSION-linux-amd64-setup.run and answer the prompts.$XDG_DATA_HOME/impleotv/libmisb/VERSION, defaulting to ~/.local/share/impleotv/libmisb/VERSION
macOSarm64 (Apple silicon)Open libmisb-sdk-VERSION-darwin-arm64-setup.pkg in Finder. Use Customize to select components.~/Library/Application Support/ImpleoTV/libmisb/VERSION

The macOS package is unsigned. Gatekeeper may block a download, and managed Macs may require administrator approval under your organization's software policy. The portable ZIP is also available. For development, use the compiler or runtime listed in your language's native quickstart.

First decode​

Open a terminal in the installed SDK root. With the web component and Node.js installed, run node web/example.mjs. Look for demo, revision 19 and timestamp 9007199254740993. For native code, decode the same packet in your language. You can also copy the SDK root into a project and use those same relative paths.

Unattended installation​

  • Windows — Run the setup executable with /S. Add /NATIVEONLY to omit the web component on a fresh installation.
  • Linux — Run the installer with sh ./libmisb-sdk-VERSION-linux-amd64-setup.run --yes. Add --native-only for native bindings alone.
  • macOS — Run installer -pkg ./libmisb-sdk-VERSION-darwin-arm64-setup.pkg -target CurrentUserHomeDirectory. For native only, add -applyChoiceChangesXML native-only.plist with the following file.
<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0"><array><dict>
  <key>choiceIdentifier</key><string>web</string>
  <key>choiceAttribute</key><string>selected</string>
  <key>attributeSetting</key><integer>0</integer>
</dict></array></plist>

Repair or remove one version​

Run the same installer again to restore its supplied files or add the web component. Keep your own application in separate files. For removal on Windows, select the version in Installed apps. On macOS or Linux, run ./uninstall.sh from its SDK root. Customer-created files and other installed versions remain available.
